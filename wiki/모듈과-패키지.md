# 모듈과 패키지

## import

`import("경로")`는 다른 `.bang` 파일을 실행하고, 그 파일의 **최상위 이름들을 담은 맵**을 돌려줍니다.

<!-- file: lib/geometry.bang -->
```bang
// lib/geometry.bang
let PI = 3.14159

fn area(r) {
    return PI * r * r
}

fn describe(r) {
    return f"반지름 {r}: 넓이 {area(r):.2f}"
}

print("geometry 로드됨")
```

```bang
// main.bang
let geo = import("lib/geometry.bang")
let again = import("lib/geometry.bang")   // 두 번째는 캐시에서 — 다시 실행하지 않음
print(geo.describe(2))
print(geo.PI, keys(geo))
```

출력:

```text
geometry 로드됨
반지름 2: 넓이 12.57
3.14159 [PI, area, describe]
```

- 모듈은 프로그램 전체에서 **한 번만 실행**되고, 그 뒤로는 같은 결과를 돌려줍니다.
- 최상위 `let`과 `fn`이 모두 공개됩니다. 숨기는 문법은 없습니다(이름 앞 `_`는 관례일 뿐).
- 모듈 안 함수는 자기 모듈의 다른 함수와 변수를 그대로 씁니다.
- 순환 import(a → b → a)는 순환 경로를 보여 주는 `import` 에러가 됩니다.

### 경로를 찾는 규칙

| `import(...)` 인자 | 찾는 곳 |
|---|---|
| `.bang`으로 끝나거나 `/`가 들어간 경로 | 그 경로 그대로 |
| 바레 이름 `"name"` | `./name.bang` → `bang_modules/name/name.bang` → `bang_modules/name/main.bang` → `bang_modules/name/lib.bang` → `BANG_PATH`의 각 디렉터리 |

> **주의 (v0.46.0)**: 상대 경로는 import를 쓴 파일의 위치가 아니라 **`bang`을 실행한 현재 디렉터리** 기준입니다. `lib/a.bang`이 같은 폴더의 `b.bang`을 가져오려면 `import("lib/b.bang")`으로 써야 하고, 프로그램은 프로젝트 루트에서 실행해야 합니다. 여러 곳에서 실행해야 한다면 공용 모듈 디렉터리를 `BANG_PATH`에 넣으세요.

```sh
BANG_PATH=/home/me/bang-libs:/opt/bang bang main.bang
```

## 패키지

중앙 레지스트리 없이 **git 저장소**를 패키지로 씁니다. `git`이 설치되어 있어야 합니다.

```sh
bang add mathutils https://github.com/user/mathutils          # 기본 브랜치
bang add webkit https://github.com/user/webkit@v1.2.0          # 태그·브랜치·커밋 고정
bang install                                                   # bang.toml의 의존성 전부 받기
```

`bang add`는 저장소를 `bang_modules/<이름>/`에 받고(`git clone`) `bang.toml`의 `[dependencies]`에 기록합니다. 이미 `bang_modules/<이름>/`이 있으면 다시 받지 않습니다.

```toml
[dependencies]
mathutils = "https://github.com/user/mathutils"
webkit = "https://github.com/user/webkit@v1.2.0"
```

> **알려진 문제 (v0.46.0)**: `bang add`는 `bang.toml`을 `[dependencies]` 섹션만으로 다시 씁니다. `bang new`가 만든 `[package]` 섹션(이름·버전)은 이때 지워집니다. 지금은 `[package]`를 읽는 기능이 없어 동작에는 영향이 없습니다.

패키지를 다시 받으려면(`@rev`를 바꾼 경우 등) `bang_modules/<이름>/`을 지우고 `bang install`을 실행하세요.

받은 패키지는 바레 이름으로 가져옵니다:

<!-- norun -->
```bang
let mathutils = import("mathutils")
print(mathutils.gcd_all([12, 18, 24]))
```

### 패키지 만들기

패키지는 그냥 `.bang` 파일이 든 git 저장소입니다. 진입 파일을 `<이름>.bang`, `main.bang`, `lib.bang` 중 하나로 두면 됩니다.

```text
mathutils/
├── mathutils.bang     ← import("mathutils")가 실행하는 파일
├── mathutils_test.bang
└── README.md
```

`bang_modules/`는 `bang new`가 만드는 `.gitignore`에 이미 들어 있습니다. 협업자는 저장소를 받은 뒤 `bang install`만 실행하면 됩니다.
