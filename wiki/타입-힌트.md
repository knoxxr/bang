# 타입 힌트 (선택)

bang은 동적 타입 언어입니다. 타입 표기는 **쓰고 싶은 곳에만** 쓰면 되고(점진적 타이핑), 표기한 곳은 두 번 검사됩니다.

1. **실행 전**: `bang check`가 확실한 충돌을 찾아 줍니다.
2. **실행 중**: 표기한 경계(변수 대입, 함수 진입, `return`)에서 값의 타입을 확인하고, 다르면 `type` 에러를 냅니다.

## 문법

```bang
let total: int = 10
let name: str = "bang"

fn add(a: int, b: int) -> int {
    return a + b
}

fn greet(name: str, times: int = 1) -> str {
    return repeat("hi " + name + " ", times)
}

print(add(total, 5), greet(name))
```

출력:

```text
15 hi bang 
```

쓸 수 있는 타입 이름: `int` `float` `bool` `str` `bytes` `list` `map` `any`

- `any`는 무엇이든 통과합니다(표기하지 않은 것과 같음).
- `list`·`map`은 안쪽 원소 타입까지 적지 않습니다(`list[int]` 같은 문법 없음).
- 타입은 정확히 일치해야 합니다. `float` 자리에 정수 `1`을 넣으면 에러입니다 — `1.0`으로 쓰세요.
- `nil`을 허용하는 "있거나 없는" 타입은 없습니다. `nil`이 올 수 있으면 표기를 생략하거나 `any`를 쓰세요.

> **알려진 문제 (v0.46.0)**: SPEC에는 `fn`과 `nil`도 타입 이름으로 적혀 있지만, 둘 다 키워드라서 현재는 `let f: fn = ...`가 파스 오류를 냅니다. 함수 값에는 `any`를 쓰거나 표기를 생략하세요.

## 실행 중 검사

```bang
fn half(x: int) -> int {
    return x / 2            // `/`는 항상 float를 돌려줌 → 반환 타입 불일치
}
try {
    half(3)
} catch e {
    print(e.kind, "|", e.message)
}

fn add(a: int, b: int) -> int {
    return a + b
}
try {
    add(1, "2")
} catch e {
    print(e.kind, "|", e.message)
}
```

출력:

```text
type | 타입 불일치: int 기대, Float 받음
type | 타입 불일치: int 기대, Str 받음
```

첫 번째 예처럼 타입 힌트는 실수를 일찍 잡아 줍니다. 정수 몫을 원했다면 `idiv(x, 2)`를 쓰면 됩니다.

## bang check

실행하지 않고 검사만 합니다. 파스 오류, 정의되지 않은 이름, 인자 수 불일치, 그리고 타입 힌트끼리의 확실한 충돌을 보고합니다.

<!-- norun -->
```bang
fn add(a: int, b: int) -> int {
    return a + b
}
let x: int = "hello"
print(add(1, "2"))
```

```text
$ bang check tc.bang
타입 오류: 타입 불일치: 'x'은 int 인데 str 값이 대입됨
  |
  4 | let x: int = "hello"
  | ^
타입 오류: 'add' 인자 2: int 기대, str 전달
  |
  5 | print(add(1, "2"))
  |       ^
```

문제가 있으면 종료 코드 1, 없으면 `OK: 파일이름`을 출력하고 0으로 끝납니다. CI에 넣기 좋습니다.

`bang check`는 **확실한 충돌만** 보고합니다. 타입을 모르는 값(표기 없는 변수, 대부분의 함수 결과)이 끼면 통과시킵니다. 즉 거짓 경보는 없지만, 모든 오류를 잡아 주지도 않습니다 — 나머지는 실행 중 검사가 잡습니다.

## 언제 쓰면 좋은가

- 여러 사람이 쓰는 함수의 **매개변수와 반환값**: 문서 역할도 합니다.
- 외부 입력(JSON, CSV, 사용자 입력)을 처음 받는 **경계**: 잘못된 데이터가 깊이 들어가기 전에 멈춥니다.
- 작은 스크립트에는 생략해도 됩니다. 타입 힌트가 필수가 되는 일은 없습니다.
