# 컬렉션 — 리스트와 맵

## 리스트

```bang
let xs = [5, 3, 8]
print(xs[0], xs[-1], len(xs))   // 음수 인덱스는 뒤에서부터
xs[0] = 50                      // 원소 대입
xs += [1]                       // 뒤에 추가
print(xs)
print(xs[1:3], xs[:2], xs[-2:]) // 슬라이스 [시작:끝], 끝은 포함 안 함
print(8 in xs, 77 not in xs)
```

출력:

```text
5 8 3
[50, 3, 8, 1]
[3, 8] [50, 3] [8, 1]
true true
```

범위를 벗어난 인덱스는 에러입니다. 슬라이스는 Python처럼 범위를 넘으면 잘라 맞춥니다.

### 리스트 함수

모든 함수는 `f(xs, ...)`로도, 메서드처럼 `xs.f(...)`로도 부를 수 있습니다([함수와 클로저](함수와-클로저#메서드-문법) 참고).

```bang
let xs = [50, 3, 8, 1]
print(xs.sort(), xs.reverse(), xs.pop())
print(xs.map(fn(x) { return x * 2 }).filter(fn(x) { return x > 10 }))
print(reduce(xs, fn(acc, x) { return acc + x }, 0), sum(xs), min(xs), max(xs))
print(index_of(xs, 8), index_of(xs, 77))
print(sort_by(["ccc", "a", "bb"], fn(s) { return len(s) }))
print(zip([1, 2], ["a", "b"]), flat([[1], [2, 3]]), unique([1, 1, 2]))
print(any(xs, fn(x) { return x > 40 }), all(xs, fn(x) { return x > 40 }))
print(union([1, 2], [2, 3]), intersect([1, 2], [2, 3]), difference([1, 2], [2, 3]))
```

출력:

```text
[1, 3, 8, 50] [1, 8, 3, 50] 1
[100, 16]
62 62 1 50
2 -1
[a, bb, ccc]
[[1, a], [2, b]] [1, 2, 3] [1, 2]
true false
[1, 2, 3] [2] [1]
```

| 함수 | 설명 |
|---|---|
| `push(xs, v)` | `v`를 붙인 **새 리스트** (`xs += [v]`와 같음) |
| `pop(xs)` | 마지막 원소를 돌려줌 (**지우지 않음** — 지우려면 `xs = xs[:-1]`) |
| `sort(xs)`, `reverse(xs)` | 정렬된/뒤집힌 새 리스트 |
| `sort_by(xs, key)` | 키 함수 결과로 정렬 |
| `map`, `filter`, `reduce(xs, f, 초깃값)` | 고차 함수 |
| `any(xs, f)`, `all(xs, f)` | 하나라도/전부 참인가 |
| `sum`, `min`, `max` | 합계, 최솟값, 최댓값 (`min(xs)` 또는 `min(a, b)`) |
| `index_of(xs, v)` | 위치, 없으면 `-1` |
| `enumerate(xs)`, `zip(a, b)`, `flat(xs)` | `[i, x]` 쌍, 짝짓기, 한 단계 펼치기 |
| `unique`, `union`, `intersect`, `difference` | 중복 제거, 집합 연산 (결과는 리스트) |
| `slice(xs, s, e)` | 함수형 슬라이스 (음수는 0으로 취급 — 문법 슬라이스 `xs[s:e]`를 권장) |

집합 전용 타입은 없습니다. 리스트와 `unique`/`union`/`intersect`/`difference`를 쓰세요.

## 맵

맵은 키→값 사전입니다. **넣은 순서를 기억합니다**(Python dict와 같음).

```bang
let m = {"name": "bang", "ver": 46}
m["lang"] = "rust"           // 추가
m.ver = 47                   // m["ver"] = 47 과 같음
print(m)
print(m.name, m["ver"], len(m))
print(keys(m), values(m))
print("name" in m, has(m, "x"), get(m, "x", 0))
print(merge({"a": 1}, {"b": 2, "a": 9}))
```

출력:

```text
{name: bang, ver: 47, lang: rust}
bang 47 3
[name, ver, lang] [bang, 47, rust]
true false 0
{a: 9, b: 2}
```

### 없는 키는 에러

없는 키를 읽으면 조용히 `nil`이 되지 않고 에러가 납니다. 키가 없을 수 있으면 `get(m, k, 기본값)`, `has(m, k)`, `k in m`을 쓰세요.

```bang
let m = {"a": 1}
print(m.b)
```

에러 출력:

```text
[2:7] 런타임 오류: 맵에 키 'b' 없음 (없을 수 있으면 get(m, k, 기본값) 또는 has(m, k))
  |
  2 | print(m.b)
  |       ^
```

단어 세기 같은 누적은 `get`으로 씁니다:

```bang
let counts = {}
for w in "the cat and the hat".split(" ") {
    counts[w] = get(counts, w, 0) + 1
}
print(counts)
```

출력:

```text
{the: 2, cat: 1, and: 1, hat: 1}
```

### 키의 타입

키는 **문자열 또는 정수**입니다. `1`과 `"1"`은 서로 다른 키입니다. 실수·리스트 등은 키가 될 수 없습니다(에러).

```bang
let n = {1: "정수 키", "1": "문자열 키"}
print(n[1], n["1"])
```

출력:

```text
정수 키 문자열 키
```

맵 리터럴에서 따옴표 없는 이름은 **문자열 키**입니다(JavaScript와 같음). 변수 값을 키로 쓰려면 대입으로 넣으세요.

```bang
let k = "zz"
let m = {a: 1, k: 2}     // 키는 "a"와 "k" (변수 k의 값이 아님)
m[k] = 3                 // 키 "zz"
print(m)
```

출력:

```text
{a: 1, k: 2, zz: 3}
```

### 키 지우기

키를 지우는 내장 함수는 아직 없습니다. 필요한 키만 골라 새 맵을 만드세요.

```bang
let m = {"a": 1, "b": 2, "c": 3}
let without_b = {}
for k, v in m {
    if k != "b" { without_b[k] = v }
}
print(without_b)
```

출력:

```text
{a: 1, c: 3}
```

## 중첩 대입

```bang
let grid = [[0, 0], [0, 0]]
grid[1][0] = 7
let cfg = {"db": {"port": 1}}
cfg.db.port = 5432
cfg["db"]["host"] = "localhost"
print(grid, cfg)
```

출력:

```text
[[0, 0], [7, 0]] {db: {port: 5432, host: localhost}}
```

## 값 의미론 — 가장 중요한 규칙

리스트·맵·문자열은 **값**입니다. 다른 변수에 넣거나, 함수에 넘기거나, 반환하거나, `spawn`·채널로 보내면 **복사본**이 갑니다. 한쪽을 바꿔도 다른 쪽은 그대로입니다.

```bang
let a = [1, 2]
let b = a
b += [3]
print(a, b)

fn add_item(list) {
    list += [99]
    return list
}
let c = add_item(a)
print(a, c)
```

출력:

```text
[1, 2] [1, 2, 3]
[1, 2] [1, 2, 99]
```

Python이라면 `a`도 바뀌었을 것입니다. bang에서 이렇게 정한 이유는 동시성입니다: 작업 사이에 같은 리스트를 함께 바꾸는 일이 원천적으로 불가능하므로 락 없이도 데이터 경쟁이 생기지 않습니다.

비용 걱정은 하지 않아도 됩니다. 내부적으로 복사는 **실제로 바꿀 때만** 일어나고(copy-on-write), 변수 하나만 쥐고 있는 리스트를 `xs[i] = v`나 `xs += [v]`로 바꾸면 복사 없이 제자리에서 바뀝니다.

그래서 리스트를 "제자리에서 바꾸는" 메서드는 없습니다. 결과를 다시 대입하세요:

| Python | bang |
|---|---|
| `xs.append(v)` | `xs += [v]` |
| `xs.sort()` | `xs = xs.sort()` |
| `xs.pop()` | `let last = xs[-1]` 다음 `xs = xs[:-1]` |
| `d.update(other)` | `d = merge(d, other)` |

새 값을 돌려주는 호출의 결과를 버리면 실수를 알려 줍니다:

```bang
let xs = [1]
xs.push(2)
```

에러 출력:

```text
[2:1] 런타임 오류: x.push(...)의 결과가 버려짐 — push은(는) 새 값을 돌려줄 뿐 x를 바꾸지 않습니다. x = x.push(...)처럼 대입하세요 (리스트 추가는 xs += [v])
  |
  2 | xs.push(2)
  | ^
```

## 출력 모양에 대해

`print`는 리스트·맵 안의 문자열에 따옴표를 붙이지 않습니다(`[a, bb]`). 그래서 `{1: "x"}`와 `{"1": "x"}`가 똑같이 `{1: x}`로 보입니다. 정확한 모양이 필요하면 `json_stringify`를 쓰세요.

```bang
print(json_stringify({"name": "bang", "tags": ["a", "b"]}))
```

출력:

```text
{"name":"bang","tags":["a","b"]}
```
