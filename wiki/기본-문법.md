# 기본 문법

## 문장과 줄바꿈

bang에는 세미콜론이 없습니다. **줄바꿈이 문장의 끝**입니다. 한 문장을 여러 줄에 걸쳐 쓰려면 다음 중 하나를 쓰세요.

- 괄호 `(` `[` 안에서는 줄바꿈이 무시됩니다.
- 줄 끝이 이항 연산자(`+`, `and` 등)나 콤마이면 다음 줄로 이어집니다.

```bang
let total = 1 +
    2 +
    3
let xs = [
    10,
    20,
]
print(total, xs)
```

출력:

```text
6 [10, 20]
```

주석은 `// 한 줄`과 `/* 여러 줄 */` 두 가지입니다.

## 변수

```bang
let x = 10          // 선언
x = 20              // 재대입
x += 5              // 복합 대입: += -= *= /= %=
let 이름 = "방"      // 한글 식별자 가능
print(x, 이름)
```

출력:

```text
25 방
```

선언하지 않은 이름을 쓰면 실행 전에 에러가 납니다(오타가 조용히 `nil`이 되지 않습니다).

## 값의 종류

| 타입 | 예 | `type(x)` |
|---|---|---|
| 정수 (64비트) | `42`, `-7`, `1_000`, `0xff`, `0b1010`, `0o17` | `Int` |
| 실수 | `3.14`, `1e3`, `2.5e-3` | `Float` |
| 불리언 | `true`, `false` | `Bool` |
| 문자열 (UTF-8) | `"hi"`, `"""여러 줄"""`, `f"{x}"` | `Str` |
| 없음 | `nil` | `Nil` |
| 리스트 | `[1, 2, 3]` | `List` |
| 맵 | `{"a": 1}` | `Map` |
| 함수 | `fn(x) { return x }` | `Function` |
| 바이트 | `bytes_from_str("a")` | `Bytes` |
| 채널 | `channel()` | `Channel` |

```bang
print(type(1), type(1.5), type("s"), type([]), type({}), type(nil), type(true))
```

출력:

```text
Int Float Str List Map Nil Bool
```

## 산술

```bang
print(7 + 2, 7 - 2, 7 * 2)
print(7 / 2, 8 / 2)          // `/`는 항상 실수
print(idiv(7, 2), 7 % 3)     // 정수 몫은 idiv
print(pow(2, 10), pow(2.0, 0.5))
print(0.1 + 0.2)
```

출력:

```text
9 5 14
3.5 4.0
3 1
1024 1.4142135623730951
0.30000000000000004
```

알아 둘 규칙:

- `/`는 항상 실수를 돌려줍니다. 정수 몫은 `idiv(a, b)`입니다(내림 — `idiv(-7, 2)`는 `-4`). `//`는 주석이라 연산자로 쓸 수 없습니다.
- `%`의 부호는 왼쪽 피연산자를 따릅니다: `-7 % 3`은 `-1`입니다(Python은 `2`).
- 정수와 실수를 섞으면 실수가 됩니다. 실수는 항상 소수점과 함께 표시됩니다(`4.0`, `1000.0`).
- 정수 오버플로는 조용히 넘어가지 않고 에러입니다.
- 0으로 나누면 에러입니다.

```bang
print(9223372036854775807 + 1)
```

에러 출력:

```text
[1:7] 런타임 오류: 정수 오버플로: + 결과가 64비트 범위를 벗어남
  |
  1 | print(9223372036854775807 + 1)
  |       ^
```

숫자가 아닌 값과의 산술도 에러입니다. 문자열과 숫자를 이으려면 `str()`이나 f-문자열을 쓰세요.

```bang
print("a" + 1)
```

에러 출력:

```text
[1:7] 런타임 오류: +: Str + Int 연산 불가
  |
  1 | print("a" + 1)
  |       ^
```

## 비교와 논리

```bang
print(1 == 1.0, 1 != "1", "a" < "b", [1, 2] == [1, 2])
print(2 < 3 and 3 < 4, not true)
print(nil or "기본값", 0 or 5, 1 and 2)
```

출력:

```text
true true true true
true false
기본값 5 2
```

- `and`/`or`는 Python처럼 피연산자 값 자체를 돌려줍니다(`nil or "기본값"` → `"기본값"`).
- 비교 연결(`1 < 2 < 3`)은 지원하지 않습니다. `1 < 2 and 2 < 3`으로 쓰세요.
- 맵의 `==`는 키 순서와 상관없이 내용으로 비교합니다.

### 참과 거짓

Python과 같습니다. `false`, `nil`, `0`, `0.0`, `""`, `[]`, `{}`, 빈 바이트가 거짓이고 나머지는 모두 참입니다.

```bang
let items = []
if not items {
    print("비어 있음")
}
print(bool(""), bool("0"), bool([0]))
```

출력:

```text
비어 있음
false true true
```

## 문자열

```bang
let s = "안녕\t탭\n줄바꿈 \"따옴표\" \\ 역슬래시"
print(s)
let long = """여러 줄
문자열"""
print(long)
print(len("한글"), "한글"[0], "hello"[1:3])
print("bang" + "!", "ab" in "cabd")
```

출력:

```text
안녕	탭
줄바꿈 "따옴표" \ 역슬래시
여러 줄
문자열
2 한 el
bang! true
```

`len`과 인덱스는 바이트가 아니라 **문자** 단위입니다. 이스케이프는 `\n \t \r \0 \\ \"`입니다.

### f-문자열과 형식 지정

`f"..."` 안의 `{식}`이 값으로 바뀝니다. `{식:형식}`으로 모양을 정할 수 있고, 중괄호 자체는 `{{` `}}`로 씁니다.

```bang
let name = "bang"
let pi = 3.14159
print(f"이름: {name}, 길이: {len(name)}, 두 배: {len(name) * 2}")
print(f"{pi:.2f} | {1234567:,} | {42:05d} | {255:x} | {5:b} | {0.25:.0%}")
print(f"[{"x":>5}] [{"x":<5}] [{"x":^5}] [{"x":*^5}]")
print(f"{{중괄호}}")
print(format("{} + {} = {:.1f}", 1, 2, 3))
```

출력:

```text
이름: bang, 길이: 4, 두 배: 8
3.14 | 1,234,567 | 00042 | ff | 101 | 25%
[    x] [x    ] [  x  ] [**x**]
{중괄호}
1 + 2 = 3.0
```

형식 지정자 문법: `[[채움]정렬][0][너비][,][.정밀도][종류]`

- 정렬: `<` 왼쪽, `>` 오른쪽, `^` 가운데
- 종류: `f` 고정 소수점, `d` 정수, `x` 16진수, `b` 2진수, `%` 백분율
- `,`는 천 단위 구분 기호

## 형 변환

```bang
print(str(1) + "개", int("42"), float("2.5"), int(3.9))
print(round(2.5), round(-2.5), floor(2.7), ceil(2.1))
```

출력:

```text
1개 42 2.5 3
3 -3 2 3
```

`int("abc")`처럼 변환할 수 없으면 에러입니다. `round`는 .5를 0에서 먼 쪽으로 올립니다(Python의 은행가 반올림과 다름). `floor`/`ceil`/`round`는 정수를 돌려줍니다.

## 제어 흐름

### if

```bang
let score = 85
if score >= 90 {
    print("A")
} else if score >= 80 {
    print("B")
} else {
    print("C")
}
```

출력:

```text
B
```

`elif`가 아니라 `else if`입니다. 조건에 괄호는 필요 없고, 본문의 `{ }`는 필수입니다.

### if 식

값이 필요한 자리에 `if`를 쓰면 식이 됩니다. 이때 `else`는 필수이고, 각 갈래의 마지막 문장이 값입니다.

```bang
let n = 7
let kind = if n % 2 == 0 { "짝수" } else { "홀수" }
print(kind)
```

출력:

```text
홀수
```

### while, break, continue

```bang
let i = 0
while true {
    i += 1
    if i == 2 { continue }
    if i > 4 { break }
    print(i)
}
```

출력:

```text
1
3
4
```

### for-in

리스트, 문자열(문자), 맵(키), 바이트(정수), 채널(닫힐 때까지)을 순회합니다.

```bang
for x in [10, 20] { print(x) }
for c in "가나" { print(c) }
for i in range(3) { print(i) }
for i, x in enumerate(["a", "b"]) { print(i, x) }
for k, v in {"x": 1, "y": 2} { print(k, v) }
```

출력:

```text
10
20
가
나
0
1
2
0 a
1 b
x 1
y 2
```

`range(끝)`, `range(시작, 끝)`, `range(시작, 끝, 간격)`은 리스트를 만듭니다.

## 키워드 전체

`let fn if else while for in return break continue and or not spawn parallel try catch throw true false nil`

`import`, `channel`, `send`, `recv`, `parallel_map` 등은 키워드가 아니라 [내장 함수](표준-라이브러리)입니다.
