# 설치와 첫 실행

## 설치

```sh
# macOS (Homebrew)
brew install knoxxr/tap/bang

# Linux / macOS (설치 스크립트)
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/knoxxr/bang/releases/latest/download/bang-installer.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://github.com/knoxxr/bang/releases/latest/download/bang-installer.ps1 | iex"

# 소스에서 (Rust 툴체인 필요)
cargo install --git https://github.com/knoxxr/bang
```

설치를 확인합니다:

```sh
$ bang --version
bang 0.48.0
```

> 설치 파일과 바이너리는 GitHub 릴리스에 올라온 버전 기준입니다. 최신 개발 버전이 필요하면 소스에서 설치하세요.

## 첫 프로그램

`hello.bang` 파일을 만듭니다:

```bang
print("hello, bang")
let name = "세계"
print(f"안녕, {name}!")
```

출력:

```text
hello, bang
안녕, 세계!
```

실행 방법은 여러 가지입니다:

```sh
bang hello.bang              # 파일 실행 (bang run hello.bang 과 같음)
echo 'print(1 + 2)' | bang - # 표준 입력에서 읽어 실행
bang                         # 인자 없이 → 대화형 REPL
```

스크립트 뒤에 붙인 인자는 `args()`로 받습니다. Python의 `sys.argv`처럼 첫 원소는 스크립트 경로입니다.

<!-- norun -->
```bang
// greet.bang
let argv = args()
let name = if len(argv) > 1 { argv[1] } else { "익명" }
print(f"안녕, {name}! (인자 {len(argv) - 1}개)")
```

```text
$ bang greet.bang 방 --loud
안녕, 방! (인자 2개)
```

맨 첫 줄에 shebang을 넣고 실행 권한을 주면 스크립트처럼 바로 실행할 수 있습니다:

```bang
#!/usr/bin/env bang
print("직접 실행")
```

```sh
chmod +x hello.bang
./hello.bang
```

## REPL

`bang`만 입력하면 REPL이 열립니다. 앞에서 정의한 변수와 함수가 계속 살아 있고, 에러가 나도 세션은 유지됩니다.

```text
$ bang
Bang REPL v0.48.0  (종료: exit(0) 또는 Ctrl+C)

>>> let xs = [3, 1, 2]
>>> print(xs.sort())
[1, 2, 3]
>>> fn sq(x) { return x * x }
>>> print(parallel_map(xs, sq))
[9, 1, 4]
>>> exit(0)
```

REPL은 Python처럼 식의 값을 자동으로 보여 주지 않습니다. 값을 보려면 `print(...)`로 감싸세요. 특히 `xs.sort()`처럼 새 값을 돌려주는 호출을 단독으로 쓰면 "결과가 버려짐" 에러가 납니다 — [컬렉션](컬렉션)의 값 의미론을 참고하세요.

## 새 프로젝트 만들기

```sh
$ bang new myapp
$ cd myapp
$ bang main.bang
```

`bang new`는 `main.bang`, 의존성 매니페스트 `bang.toml`, `.gitignore`를 만듭니다. 의존성 관리는 [모듈과 패키지](모듈과-패키지)를 보세요.
