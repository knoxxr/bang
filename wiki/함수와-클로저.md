# 함수와 클로저

## 함수 정의

```bang
fn add(a, b) {
    return a + b
}
let sub = fn(a, b) { return a - b }    // 익명 함수를 변수에
print(add(2, 3), sub(5, 1), type(add))
```

출력:

```text
5 4 Function
```

`fn add(...) {...}`는 `let add = fn(...) {...}`의 줄임입니다. 둘 다 똑같이 동작합니다.

- 값을 돌려주려면 `return`을 써야 합니다. `return`이 없으면 `nil`을 돌려줍니다(마지막 식이 자동으로 반환되지 않습니다).
- 인자 수가 맞지 않으면 실행 전에 에러가 납니다.
- 재귀, 상호 재귀, 아래쪽에 정의된 함수 호출 모두 됩니다.
- 한 줄에 문장 여러 개를 쓸 수 없습니다. `{ if c { return 1 } return 2 }`가 아니라 줄을 나누세요.

```bang
fn is_even(n) {
    if n == 0 { return true }
    return is_odd(n - 1)    // 아래에 정의된 함수
}
fn is_odd(n) {
    if n == 0 { return false }
    return is_even(n - 1)
}
print(is_even(10))
```

출력:

```text
true
```

## 기본값 매개변수

```bang
fn greet(name, greeting = "안녕", times = 1) {
    return repeat(f"{greeting} {name}! ", times)
}
print(greet("bang"))
print(greet("bang", "hi", 2))
```

출력:

```text
안녕 bang! 
hi bang! hi bang! 
```

- 기본값이 있는 매개변수는 뒤쪽에만 둘 수 있습니다.
- 기본값은 **호출할 때마다 새로 계산**됩니다. Python의 `def f(xs=[])` 함정(호출끼리 리스트 공유)이 없습니다.
- 키워드 인자(`greet(times=2)`)와 가변 인자(`*args`)는 없습니다. 선택 항목이 많으면 맵을 하나 받으세요.

## 함수는 값

함수를 변수에 담고, 인자로 넘기고, 반환할 수 있습니다.

```bang
fn apply_twice(f, x) {
    return f(f(x))
}
print(apply_twice(fn(x) { return x * 3 }, 2))

fn adder(n) {
    return fn(x) { return x + n }
}
let add10 = adder(10)
print(add10(5))
```

출력:

```text
18
15
```

## 클로저

안쪽 함수는 바깥 변수를 **붙잡습니다**. 붙잡은 변수를 바꾸면 그 변수를 붙잡은 모든 함수가 바뀐 값을 봅니다(Python과 같은 방식).

```bang
fn make_counter() {
    let n = 0
    return fn() {
        n += 1
        return n
    }
}
let c1 = make_counter()
let c2 = make_counter()
print(c1(), c1(), c1(), c2())
```

출력:

```text
1 2 3 1
```

루프 안에서 만든 클로저는 루프 변수를 함께 붙잡으므로 Python과 똑같이 마지막 값을 봅니다:

```bang
let fs = []
for i in range(3) {
    fs += [fn() { return i }]
}
print(fs[0](), fs[1](), fs[2]())
```

출력:

```text
2 2 2
```

각자 다른 값을 원하면 그 값을 인자로 받는 함수를 만들어 고정하세요:

```bang
fn const_fn(v) {
    return fn() { return v }
}
let fs = []
for i in range(3) {
    fs += [const_fn(i)]
}
print(fs[0](), fs[1](), fs[2]())
```

출력:

```text
0 1 2
```

클로저가 붙잡은 변수는 **같은 작업 안에서만** 공유됩니다. `spawn`으로 다른 작업에 넘기면 클로저와 그 상태가 통째로 복사됩니다 — [동시성](동시성#작업-사이에-공유되는-것은-없다) 참고.

## 메서드 문법

`x.f(a, b)`는 `f(x, a, b)`와 같습니다(`f`가 내장 함수일 때). 그래서 호출을 이어 쓸 수 있습니다.

```bang
let words = "  Hello World  ".trim().lower().split(" ")
print(words, words.len())
print([3, 1, 2].sort().map(fn(x) { return x * 10 }))
```

출력:

```text
[hello, world] 2
[10, 20, 30]
```

`x`가 맵이고 그 맵에 같은 이름의 키가 있으면, 내장 함수 대신 맵에 든 함수를 부릅니다. 이것이 아래 "객체" 패턴의 바탕입니다.

## 클래스 대신: 맵 + 클로저

bang에는 클래스와 상속이 없습니다. 상태를 붙잡은 클로저들을 맵에 담으면 객체처럼 쓸 수 있습니다.

```bang
fn new_account(owner) {
    let balance = 0
    return {
        "owner": owner,
        "deposit": fn(amount) {
            if amount <= 0 { throw "입금액은 양수여야 합니다" }
            balance += amount
            return balance
        },
        "balance": fn() { return balance },
    }
}

let acc = new_account("kim")
acc.deposit(100)
acc.deposit(50)
print(acc.owner, acc.balance())
```

출력:

```text
kim 150
```

`acc.deposit(100)`의 반환값을 버려도 괜찮습니다. 결과를 버리면 에러가 나는 것은 `push`·`sort`처럼 새 값을 돌려주는 내장 함수뿐입니다.

> 주의: `owner` 같은 데이터 필드는 맵에 든 값이므로 `acc.owner = "lee"`로 바꿔도 다른 변수에 복사해 둔 맵에는 반영되지 않습니다(값 의미론). 함께 공유해야 하는 상태는 위의 `balance`처럼 클로저가 붙잡은 변수에 두세요.

## 이름 규칙 요약

| 하고 싶은 것 | 쓰는 법 |
|---|---|
| 함수 정의 | `fn name(a, b) { ... }` |
| 익명 함수 | `fn(x) { return x * 2 }` |
| 기본값 | `fn f(a, b = 10)` |
| 상태 있는 함수 | 클로저 (`make_counter`) |
| 객체 | 맵 + 클로저 (`new_account`) |
| 메서드처럼 호출 | `x.f(...)` = `f(x, ...)` |
