# 표준 라이브러리

내장 함수 **135개**는 import 없이 바로 씁니다. 모두 `f(x, ...)`로도 `x.f(...)`로도 부를 수 있습니다. 실패하면 `try`/`catch`로 잡을 수 있는 에러를 냅니다([에러 처리](에러-처리) 참고).

분야별 차례: [기본](#기본) · [문자열](#문자열) · [리스트](#리스트) · [맵](#맵) · [수학](#수학) · [JSON](#json) · [정규식](#정규식) · [시간과 난수](#시간과-난수) · [파일](#파일) · [경로](#경로) · [CSV](#csv) · [바이트](#바이트) · [프로세스와 환경](#프로세스와-환경) · [동시성](#동시성) · [네트워킹](#네트워킹) · [테스트](#테스트)

## 기본

| 함수 | 설명 |
|---|---|
| `print(...)` | 값을 공백으로 이어 stdout에 한 줄 출력 |
| `print_err(...)` | stderr에 출력 |
| `str(x)` `int(x)` `float(x)` `bool(x)` | 형 변환 (변환할 수 없으면 `value` 에러) |
| `len(x)` | 문자열(문자 수)·리스트·맵·바이트 길이 |
| `type(x)` | `"Int"` `"Float"` `"Str"` `"List"` `"Map"` `"Nil"` `"Bool"` `"Function"` `"Bytes"` `"Channel"` 등 |
| `range(끝)` `range(시작, 끝)` `range(시작, 끝, 간격)` | 정수 리스트 |
| `input()` | stdin에서 한 줄 (줄바꿈 제외, 입력이 끝났으면 `""`) |
| `args()` | 명령줄 전체 (`[bang 경로, 스크립트, ...]` — [알려진 문제](한계와-FAQ#알려진-문제-v0460) 참고) |
| `exit(코드)` | 즉시 종료 (`exit()`는 0) |
| `import(경로)` | 모듈 로드 → 맵 ([모듈과 패키지](모듈과-패키지)) |
| `assert(조건[, 메시지])` `assert_eq(실제, 기대)` | 검증 ([테스트](#테스트)) |

## 문자열

```bang
let s = "  Hello, World  "
print(trim(s), "|" + trim_start(s) + "|", "|" + trim_end(s) + "|")
print(split("a,b,c", ","), join(["a", "b"], "-"), replace("aaa", "a", "b"))
print(contains("hello", "ell"), starts_with("hello", "he"), ends_with("hello", "lo"))
print(upper("abc"), lower("ABC"), find("hello", "l"), find("hello", "z"))
print(chars("가나다"), repeat("ab", 3), ord("A"), chr(44032))
print(format("{:>6}|{:<6}|{:.3f}", "ab", "cd", 2.0))
```

출력:

```text
Hello, World |Hello, World  | |  Hello, World|
[a, b, c] a-b bbb
true true true
ABC abc 2 -1
[가, 나, 다] ababab 65 가
    ab|cd    |2.000
```

| 함수 | 설명 |
|---|---|
| `split(s, 구분자)` `join(리스트, 구분자)` | 나누기, 잇기 |
| `trim` `trim_start` `trim_end` | 공백 제거 |
| `replace(s, 찾을, 바꿀)` | 모두 바꾸기 |
| `contains(s, 부분)` `starts_with` `ends_with` | 포함 검사 (`contains`는 문자열 전용 — 리스트는 `x in xs`) |
| `find(s, 부분)` | 문자 위치, 없으면 `-1` |
| `upper` `lower` | 대소문자 |
| `chars(s)` | 문자 리스트 |
| `repeat(s, n)` | 반복 (`"ab" * 3`은 지원하지 않음) |
| `ord(s)` `chr(n)` | 문자 ↔ 코드포인트 |
| `format(형식, ...)` | `{}` 자리 채우기, `{:형식}` 지정 ([f-문자열과 같은 규칙](기본-문법#f-문자열과-형식-지정)) |

## 리스트

`push` `pop` `sort` `sort_by` `reverse` `map` `filter` `reduce` `any` `all` `flat` `enumerate` `zip` `sum` `min` `max` `unique` `index_of` `slice` `union` `intersect` `difference` — 설명과 예는 [컬렉션](컬렉션#리스트-함수)에 있습니다.

`min`/`max`는 리스트 하나(`min(xs)`) 또는 값 두 개(`min(a, b)`)를 받습니다.

## 맵

| 함수 | 설명 |
|---|---|
| `keys(m)` `values(m)` | 넣은 순서대로 |
| `has(m, k)` | 키가 있나 (`k in m`과 같음) |
| `get(m, k, 기본값)` | 없으면 기본값 |
| `merge(a, b)` | 합친 새 맵 (같은 키는 `b`가 이김) |

## 수학

```bang
print(abs(-3), sqrt(16), floor(-2.5), ceil(-2.5), round(2.567))
print(pow(2, 10), idiv(7, 2), gcd(12, 18), clamp(15, 0, 10), sign(-3))
print(sin(0), cos(0), log(e()), log10(1000), exp(0), pi())
print(min(3, 1), max([4, 9]), sum([1.5, 2]))
```

출력:

```text
3 4.0 -3 -2 3
1024 3 6 10 -1
0.0 1.0 1.0 3.0 1.0 3.141592653589793
1 9 3.5
```

`abs sqrt floor ceil round pow idiv gcd clamp sign sin cos tan log log10 exp pi() e() min max sum`

- `floor`/`ceil`/`round`는 정수를 돌려줍니다. `sqrt`와 삼각·로그 함수는 실수를 돌려줍니다.
- `idiv(a, b)`는 내림 정수 몫입니다(Python의 `a // b`).
- `clamp(x, 최소, 최대)`는 원래 타입을 유지합니다.

## JSON

```bang
let data = json_parse("{\"name\": \"Al\", \"nums\": [1, 2.5, null, true]}")
print(data.name, data.nums)
print(json_stringify({"b": 1, "a": [1, nil, "x"]}))
```

출력:

```text
Al [1, 2.5, nil, true]
{"b":1,"a":[1,null,"x"]}
```

- 객체 → 맵(문서의 키 순서 유지), 배열 → 리스트, `null` → `nil`.
- `json_stringify`는 맵에 넣은 순서대로 키를 씁니다. 함수·채널·바이트는 직렬화할 수 없습니다(에러).

## 정규식

외부 라이브러리 없는 자체 엔진입니다. 패턴 문자열 안의 `\`는 `\\`로 씁니다.

```bang
print(regex_match("2026-11-23", "^\\d{4}-\\d{2}-\\d{2}$"))
print(regex_find("tel: 010-1234", "\\d+-\\d+"), regex_find("abc", "\\d"))
print(regex_find_all("a1 b22 c333", "\\d+"))
print(regex_replace("a1b2", "\\d", "#"))
print(regex_groups("kim@example.com", "(\\w+)@([\\w.]+)"))
```

출력:

```text
true
010-1234 nil
[1, 22, 333]
a#b#
[kim@example.com, kim, example.com]
```

| 함수 | 돌려주는 것 |
|---|---|
| `regex_match(s, 패턴)` | 어딘가 맞는 곳이 있나 (`^…$`로 전체 일치) |
| `regex_find(s, 패턴)` | 첫 일치 문자열, 없으면 `nil` |
| `regex_find_all(s, 패턴)` | 모든 일치 리스트 |
| `regex_replace(s, 패턴, 바꿀)` | 모두 바꾼 문자열 |
| `regex_groups(s, 패턴)` | `[전체, 그룹1, 그룹2, ...]`, 없으면 `nil` |

지원: `.` `*` `+` `?` `{n}` `{n,}` `{n,m}` `[abc]` `[^a-z]` `\d \w \s \D \W \S` `^` `$` `( )` `|`. 역참조(`\1`)와 전방 탐색은 지원하지 않습니다. 폭주하는 패턴은 단계 상한에 걸려 에러가 납니다.

## 시간과 난수

```bang
print(format_time(0), format_time(1700000000000))
let start = now_ms()
sleep(50)
print(now_ms() - start >= 50)
let r = random()
print(r >= 0 and r < 1, random_int(1, 1))
```

출력:

```text
1970-01-01 00:00:00 2023-11-14 22:13:20
true
true 1
```

| 함수 | 설명 |
|---|---|
| `now_ms()` | 유닉스 시각(밀리초) |
| `format_time(ms)` | `"YYYY-MM-DD HH:MM:SS"` (UTC) |
| `sleep(ms)` | 대기 (다른 작업은 막지 않음) |
| `random()` | `[0, 1)` 실수 |
| `random_int(최소, 최대)` | 양 끝 포함 정수 |

난수는 시간으로 시드한 빠른 PRNG입니다. 암호용으로 쓰지 마세요.

## 파일

```bang
write_file("note.txt", "첫 줄\n")
file_append("note.txt", "둘째 줄\n")
print(read_file("note.txt"))
print(file_exists("note.txt"), file_size("note.txt"), is_dir("."))
dir_create("logs/2026/11")            // 중간 디렉터리까지 생성, 이미 있어도 OK
file_move("note.txt", "logs/note.txt")
print(list_dir("logs").sort(), file_exists("note.txt"))
file_remove("logs/note.txt")
```

출력:

```text
첫 줄
둘째 줄

true 19 true
[2026, note.txt] false
```

| 함수 | 설명 |
|---|---|
| `read_file(p)` | 전체를 문자열로 (UTF-8이 아니면 에러 — 바이너리는 `file_read_bytes`) |
| `write_file(p, 내용)` `file_append(p, 내용)` | 쓰기/덧붙이기 (`str`, `bytes` 모두 가능) |
| `file_exists(p)` `is_dir(p)` `file_size(p)` | 존재, 디렉터리 여부, 바이트 크기 |
| `list_dir(p)` | 이름 리스트 (순서는 OS 마음대로 — 필요하면 정렬) |
| `dir_create(p)` | 디렉터리 생성 (중간 경로 포함) |
| `file_move(원본, 대상)` `file_remove(p)` | 이동(같은 볼륨), 파일 삭제 (디렉터리는 지우지 않음) |

## 경로

```bang
print(path_join("logs", "2026", "a.tar.gz"))
print(path_basename("/x/y/a.tar.gz"), path_dirname("/x/y/a.tar.gz"), path_ext("a.tar.gz"))
print(path_abs("x") == path_join(env_cwd(), "x"))
```

출력:

```text
logs/2026/a.tar.gz
a.tar.gz /x/y gz
true
```

경로 함수는 문자열만 다루고 파일이 실제로 있는지는 보지 않습니다. 구분자는 OS를 따릅니다(Windows는 `\`).

## CSV

```bang
let rows = csv_parse("name,age\n\"Kim, J\",30\n")
print(rows)
print(csv_stringify([["a", "b,c"], ["1", nil]]))
```

출력:

```text
[[name, age], [Kim, J, 30]]
a,"b,c"
1,

```

RFC 4180을 따릅니다(따옴표, `""` 이스케이프, 필드 안 줄바꿈, CRLF). 모든 필드는 문자열로 읽힙니다 — 숫자는 `int()`/`float()`로 바꾸세요. 위 출력에서 `[Kim, J, 30]`은 필드 2개(`"Kim, J"`와 `"30"`)입니다(리스트 안 문자열은 따옴표 없이 표시됨).

## 바이트

`str`은 항상 UTF-8입니다. 이미지 같은 바이너리 데이터는 불변 `bytes`로 다룹니다. 리터럴 문법은 없고 함수로 만듭니다.

```bang
let b = bytes_from_str("hi")
print(b, len(b), b[0], bytes_to_hex(b), bytes_to_str(bytes_from_hex("6869")))
write_file("sig.bin", bytes_from_hex("89504e47"))
let sig = file_read_bytes("sig.bin")
print(sig, sig[1:3], sig + b == bytes_from_hex("89504e476869"))
```

출력:

```text
<bytes 2: 6869> 2 104 6869 hi
<bytes 4: 89504e47> <bytes 2: 504e> true
```

`bytes_from_str` `bytes_to_str` `bytes_from_hex` `bytes_to_hex` `file_read_bytes` `tcp_read_bytes` — 인덱스(`b[i]` → 0~255 정수), 슬라이스, `+`, `==`, `len`, `for x in b`를 지원합니다. `b[i] = v`는 에러입니다(불변).

## 프로세스와 환경

```bang
let r = proc_run(["echo", "hello"])
print(r.code, r.stdout)
print(env_get("NO_SUCH_VAR_X"), type(env_get("HOME")))
```

출력:

```text
0 hello

nil Str
```

| 함수 | 설명 |
|---|---|
| `proc_run([프로그램, 인자...])` | 실행하고 끝날 때까지 기다려 `{code, stdout, stderr}` |
| `env_get(이름)` | 환경 변수, 없으면 `nil` |
| `env_cwd()` | 현재 디렉터리 |

`proc_run`은 셸을 거치지 않습니다(`"ls | wc"` 같은 문자열 명령 불가 — 셸 인젝션이 원천 차단됨). 셸 기능이 필요하면 `proc_run(["sh", "-c", "ls | wc -l"])`처럼 명시하세요. 종료 코드가 0이 아니어도 에러가 아니므로 `r.code`를 확인하세요. 실행 파일이 없으면 `io` 에러입니다.
